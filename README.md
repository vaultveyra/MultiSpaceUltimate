# MultiSpace Ultimate — نسخه 0.1.0 (مرحله ۱)

## روش ساخت APK (بدون Android Studio)
1. در github.com یک مخزن (Repository) جدید بساز.
2. تمام محتویات این پوشه (از جمله پوشه‌ی مخفی `.github`) را در مخزن آپلود کن.
3. در تب **Actions** گزینه‌ی **Build APK** را اجرا کن (Run workflow).
4. پس از سبز شدن، از پایین صفحه‌ی همان اجرا، فایل **MultiSpaceUltimate-debug-apk** را دانلود و APK را روی گوشی نصب کن.
5. اگر Build قرمز شد، متن کامل خطا را برای من بفرست.

## چه چیزی واقعی است
- شماره‌گذاری نمونه‌ها و فضاها (کوچک‌ترین شماره‌ی آزاد هر برنامه = شماره‌ی نمونه = شماره‌ی فضا)
- ذخیره‌سازی پایدار، چیدمان شبکه‌ای ۴ ستونه، درگ برای جابه‌جایی، ویرایش نام نمونه/فضا با نگه‌داشتن
- انتخاب برنامه (نصب‌شده، سیستمی، کشف در گوگل‌پلی)، داشبورد با داده‌های واقعی دستگاه

## چه چیزی هنوز نیست
- **موتور جداسازی** (اجرای مستقل نمونه‌ها). فعلاً لمس یک نمونه پیام صریح می‌دهد، نه اجرای برنامه‌ی اصلی.
- SMS Center، امنیت (PIN/بیومتریک)، پشتیبان‌گیری، ۵ زبان دیگر، Room
