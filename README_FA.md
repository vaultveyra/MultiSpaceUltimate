# MultiSpace Ultimate — نسخه پایه ۰٫۱٫۰

این بسته یک پوسته اولیه Native Android با رابط فارسی و گزارش مشخصات دستگاه است.

## محدودیت‌های صریح این نسخه
- فضاهای فعلی فقط ورودی‌های مدیریتی داخل داشبورد هستند.
- اجرای ایزوله برنامه‌های شخص ثالث پیاده‌سازی نشده است.
- Google Play Services، مدیریت حساب چندگانه، اعلان‌های مستقل و SMS هنوز پیاده‌سازی نشده‌اند.
- هیچ سازگاری‌ای برای موتور مجازی ادعا نمی‌شود.

## ساخت APK با GitHub Actions
1. یک مخزن خصوصی جدید در GitHub بسازید.
2. فایل ZIP را استخراج کنید.
3. تمام محتویات پوشه را در ریشه مخزن بارگذاری و commit کنید.
4. در تب Actions، گردش‌کار `Android Debug APK` را اجرا کنید.
5. پس از موفقیت، از بخش Artifacts فایل `MultiSpaceUltimate-debug` را دانلود کنید.

## مشخصات فنی
- Kotlin
- Jetpack Compose
- minSdk 26 (Android 8.0)
- compileSdk 35
- JDK 17
- Android Gradle Plugin 8.7.3

برای نسخه امضاشده و انتشارپذیر، بعداً کلید امضای اختصاصی و فرایند امن signing اضافه می‌شود.
