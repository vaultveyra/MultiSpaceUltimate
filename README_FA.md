# MultiSpace Ultimate 1.0.0 — Source Project

این نسخه یک مرحله ارتقای رابط و مدیریت فضاها بر پایه سورس ارسالی شماست. ساختار پروژه Android/Kotlin و گردش‌کار ساخت APK در GitHub Actions حفظ شده است.

## قابلیت‌های پیاده‌سازی‌شده در این نسخه
- صفحه‌های Dashboard، Spaces و Settings
- نمایش آیکون برنامه‌ها در شبکه ۴ ستونه شبیه صفحه اصلی گوشی
- افزودن برنامه‌های قابل‌دسترسی در پروفایل‌های اندروید
- قانون شماره‌گذاری مستقل برای هر برنامه: انتخاب اول در Space 1، انتخاب دوم در Space 2 و انتخاب سوم در Space 3
- ذخیره محلی ورودی‌ها، شماره نمونه، فضای تخصیص‌یافته، ترتیب و نام سفارشی
- تغییر نام نمایشی برنامه بدون تغییر package name
- تغییر نام Space با لمس عنوان
- جابه‌جایی بین فضاها از منوی هر آیکون و Drag & Drop بین آیکون‌ها/فضاها
- اجرای برنامه از پروفایل واقعی قابل‌دسترسی
- جست‌وجوی برنامه‌ها، فیلتر برنامه‌های نصب‌شده و سیستمی، پیوند کشف در Play Store
- زبان فارسی/انگلیسی و تم روشن/تیره
- نمایش اطلاعات پایه دستگاه و RAM
- بدون حساب آنلاین و تبلیغات

## محدودیت‌های مهم — شفاف و ضروری
این نسخه هنوز موتور کلون‌سازی/مجازی‌سازی عمومی ندارد. افزودن چند ورودی از یک package در یک پروفایل، چند نصب مستقل و چند دیتابیس مستقل ایجاد نمی‌کند. استقلال واقعی فقط وقتی وجود دارد که خود اندروید یک پروفایل جداگانه در اختیار بگذارد و آن برنامه واقعاً در آن پروفایل نصب شده باشد.

در این نسخه هنوز این موارد پیاده‌سازی نشده‌اند:
- موتور مجازی‌سازی چندنمونه‌ای یا ساخت خودکار چند Work Profile
- نصب و به‌روزرسانی مستقل APK داخل sandbox
- پوشه‌های آیکون، صفحات چندگانه قابل‌کشیدن، انیمیشن‌های لانچر پیشرفته
- SMS Center، قفل داخلی با PIN/biometric، رمزنگاری و پشتیبان‌گیری امن
- مدیریت کامل اعلان‌ها و سرویس‌های پس‌زمینه

بنابراین این نسخه را نباید کلونر واقعی یا نسخه نهایی تمام قابلیت‌های سند Master Prompt دانست. قابلیت‌ها باید مرحله‌به‌مرحله با تست روی دستگاه واقعی تکمیل شوند.

## ساخت در GitHub
1. فایل ZIP سورس را استخراج کنید.
2. محتویات پوشه پروژه را در ریشه مخزن `MultiSpaceUltimate` بارگذاری و فایل‌های قدیمی را جایگزین کنید؛ پوشه مخفی `.github` را هم منتقل کنید.
3. در GitHub وارد Actions شوید.
4. گردش‌کار `MultiSpace Ultimate Android Build` را اجرا کنید.
5. پس از موفقیت، Artifact با نام `MultiSpaceUltimate-1.0.0-debug` را دانلود کنید.
6. ZIP آرتیفکت را باز کنید و `app-debug.apk` را روی گوشی آزمایشی نصب کنید.

## مشخصات ساخت
- minSdk 26 (Android 8.0+)
- compileSdk / targetSdk 35
- JDK 17، Gradle 8.9، AGP 8.7.3، Kotlin 2.0.21
- applicationId: `com.veyra.multispace`

## تست ضروری
این سورس در این محیط با Android SDK ساخته نشده است. قبل از نصب، باید GitHub Actions سبز شود. پس از نصب، Drag & Drop، جابه‌جایی بین Spaceها، تغییر نام و اجرای برنامه‌ها را روی گوشی واقعی بررسی کنید. اگر build شکست خورد، کل متن خطا را ارسال کنید.
