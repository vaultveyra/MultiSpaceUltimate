# MultiSpace Ultimate — نسخه 0.3.0

این مخزن سورس کامل نسخه 0.3.0 برنامه MultiSpace Ultimate است.

## امکانات پیاده‌سازی‌شده
- داشبورد و سه بخش خانه، فضاها و تنظیمات
- افزودن برنامه‌های قابل اجرا از پروفایل‌های قابل دسترسی اندروید
- ساخت ورودی‌های دسترسی سریع برای برنامه‌ها
- اجرای برنامه از پروفایل مربوط به همان ورودی با `LauncherApps`
- تغییر نام و حذف ورودی‌ها
- ذخیره محلی فضاها با SharedPreferences
- زبان فارسی و انگلیسی، فارسی پیش‌فرض
- تم روشن و تاریک
- نمایش اطلاعات دستگاه و حافظه
- جست‌وجوی برنامه‌ها و پیوند به Play Store
- بدون حساب کاربری، ثبت‌نام، تبلیغات یا سرویس آنلاین

## نکته بسیار مهم درباره استقلال واقعی
این نسخه یک موتور عمومی کلون‌سازی یا مجازی‌سازی اپلیکیشن نیست. هر ورودی به یک برنامه نصب‌شده در یک پروفایل واقعی اندروید اشاره می‌کند. اگر یک برنامه فقط در پروفایل شخصی نصب باشد، افزودن چند ورودی از آن، چند نسخه مستقل ایجاد نمی‌کند.

برای داشتن نمونه جداگانه، باید Work Profile یا پروفایل دیگری توسط خود اندروید/مدیر مجاز دستگاه ایجاد شده باشد و برنامه موردنظر در آن پروفایل نیز نصب شود. این برنامه از API عمومی `LauncherApps` برای فهرست‌کردن و اجرای برنامه‌های پروفایل‌های قابل‌دسترسی استفاده می‌کند؛ امکان ایجاد خودکار Work Profile یا نصب اجباری برنامه در آن را ندارد.

## سازگاری
- حداقل Android 8.0 (API 26)
- هدف ساخت Android 15 (API 35)
- Java 17 / Kotlin 2.0.21
- Android Gradle Plugin 8.7.3
- Gradle 8.9 در GitHub Actions

سازگاری با هر دستگاه/سازنده تضمین‌شده نیست. دسترسی به پروفایل کاری و برنامه‌های آن تابع نسخه اندروید، سیاست‌های دستگاه و پیاده‌سازی سازنده است.

## ساخت APK با GitHub
1. محتویات ZIP را در ریشه مخزن `MultiSpaceUltimate` قرار بده و فایل‌های قدیمی را با نسخه جدید جایگزین کن.
2. مطمئن شو پوشه `.github/workflows` نیز آپلود شده است.
3. در GitHub به تب **Actions** برو.
4. گردش‌کار **MultiSpace Ultimate Android Build** را انتخاب کن.
5. روی **Run workflow** بزن.
6. پس از سبز شدن Build، از بخش Artifacts فایل `MultiSpaceUltimate-0.3.0-debug` را دانلود کن.
7. ZIP آرتیفکت را باز کن و `app-debug.apk` را روی گوشی نصب کن.

## نکات انتشار
این خروجی Debug است و برای نصب آزمایشی شخصی ساخته می‌شود. برای نسخه Release باید کلید امضای خصوصی اختصاصی ایجاد و به‌صورت امن نگهداری شود. کلید امضا را داخل مخزن عمومی قرار نده.

## حریم خصوصی
اطلاعات ورودی‌های فضا به‌صورت محلی در SharedPreferences برنامه ذخیره می‌شود. این نسخه هیچ اتصال شبکه‌ای یا ثبت‌نامی ندارد. لینک Play Store فقط با اقدام کاربر باز می‌شود.
