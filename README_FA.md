# MultiSpace Ultimate — نسخه پایه 0.2.0

این نسخه رابط کاربری را بازطراحی می‌کند و امکانات پایه زیر را اضافه می‌کند:
- نام انگلیسی برنامه: MultiSpace Ultimate
- داشبورد مستقل و تب‌های داشبورد، فضاها، برنامه‌ها، سازگاری و تنظیمات
- انتخاب زبان با پرچم: فارسی (پیش‌فرض)، انگلیسی، آلمانی، فرانسوی، اسپانیایی، عربی و ترکی
- تغییر جهت رابط بین RTL و LTR بر اساس زبان
- ذخیره دائمی زبان و فهرست فضاها روی دستگاه با SharedPreferences
- امکان ایجاد و حذف فضاها و حفظ آن‌ها پس از بستن و اجرای مجدد برنامه
- گزارش اولیه سازنده، مدل، نسخه اندروید، API و معماری‌های CPU

## محدودیت‌های مهم
- فضاها در این نسخه پروفایل‌های مدیریتی محلی هستند، نه محیط‌های ایزوله اندروید.
- اجرای واقعی چند نمونه مستقل از برنامه‌های شخص ثالث هنوز پیاده‌سازی نشده است.
- تب برنامه‌ها فعلاً توضیح وضعیت است و نصب/اجرای اپ‌های دیگر را انجام نمی‌دهد.
- گزارش سازگاری فعلاً مشخصات دستگاه را نشان می‌دهد و تأییدکننده سازگاری موتور مجازی نیست.
- داده‌های اولیه فضاها با SharedPreferences ذخیره می‌شوند؛ برای داده‌های پیچیده‌تر و رابطه‌ای، مهاجرت به Room در مرحله بعد انجام می‌شود.
